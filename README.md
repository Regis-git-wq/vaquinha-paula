# Vaquinha da Paula — paulaprotese-vaquinha.com.br

Site estático de uma página (`index.html`, com HTML, CSS e JS juntos), fotos em `img/`
e regras de segurança em `_headers`.

- Regras do projeto: `CLAUDE.md`
- Visual (cores, fontes, espaçamentos): `DESIGN.md`

## Como publicar
O site fica na **Netlify** (não no GitHub Pages): projeto *paulaprotese-vaquinha* →
**Deploys** → arraste a pasta com `index.html`, `img/` e `_headers`.
